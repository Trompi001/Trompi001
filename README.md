# Hi, I'm Florin 👋

**Computational and Data Science student** · 5th semester · [FH Graubünden](https://www.fhgr.ch)

I'm studying at the intersection of computer science, mathematics and data. What excites me most is **simulation**: turning physical and dynamic systems into mathematical models, solving them numerically and making the results visible. Around that, I'm building the skills to run computations and data pipelines at scale, from high-performance computing to the cloud.

---

## 🔭 Currently working on (fall semester 2026)

- 📈 **Modelling & Simulation II**: building a flow simulation as a group project, with efficient equation solvers and VTK visualization
- ☁️ **Cloud Computing**: Azure core services, Infrastructure as Code with Terraform, containers, serverless and event-driven architectures, and lakehouse data engineering with Databricks and Delta Lake
- ⚙️ **DevOps**: Git workflows, build processes, Docker, CI/CD, Kubernetes, monitoring and DevSecOps
- 🗄️ **Big Data**: data warehousing, ETL/ELT and data quality, dimensional modelling (star schema, Data Vault), OLAP and BI, plus distributed batch and stream processing (Lambda and Kappa architectures)
- 🔬 **NLP Research & Applied Project**: a small applied research project, from literature review to experiment
